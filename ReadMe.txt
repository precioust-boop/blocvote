/* Bloc-Vote by Precious Temowo */

To run this system:

1. Install Ganache from https://www.trufflesuite.com/ganache
2. Open Ganache and choose Quick start. Set the Server Port Number to 8545
3. Open Chrome - go to https://metamask.io/ - add MetaMask Extension to Chrome. Create a MetaMask account. Connect to Localhost 8545.
4. Add MetaMask accounts by importing their Private Keys. The private keys are gotten from Ganache. 
5. Copy and paste Election.sol to remix.ethereum.org and compile the code. To deploy the contract, set the environment to 'Web3 provider'.
6. Open the index.html and start using Bloc-Vote.
